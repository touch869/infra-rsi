# Workspace scaffolding

Inputs the phase-1 contracts expect on the Ascend host. They lived only in
`/root/irsi-workspace` during the first run; this directory versions them so the
flow can be rebuilt from the repository.

| file | role |
|---|---|
| `configs/tiny-qwen3/config.json` | 12-layer Qwen3 (hidden 1024) — smoke contract |
| `configs/medium-qwen3/config.json` | 24-layer Qwen3 (hidden 2048) — measurement contract |
| `configs/train_tiny.yaml` | HyperParallel training config, seq 2048, 20 steps |
| `configs/train_medium.yaml` | same, seq 4096, 20 steps (contract overrides to 32) |
| `irsi_data.py` | `PackedTensorDataset`: HF packed records → torch tensors |
| `make_data.py` | deterministic synthetic packed dataset generator |

Models are built with `from_config` (random init) and the data is synthetic. That
is deliberate: phase 1 measures throughput and peak memory under a bitwise gate,
not convergence.

## Rebuild on the host

```bash
# 1. materials (repo checkout or rsync of this directory)
cp -r workspace/. /root/irsi-workspace/

# 2. synthetic dataset (needs datasets + pyarrow, numpy<2)
cd /root/irsi-workspace
python make_data.py --out data/tiny-packed

# 3. run a contract (paths in contracts/*.yaml point here)
irsi run --contract /root/infra-rsi/contracts/tiny-qwen3.yaml \
         --runs-dir /root/irsi-workspace/runs
```

If the workspace lives elsewhere, rewrite the absolute paths first:

```bash
sed -i 's#/root/irsi-workspace#/path/to/workspace#g' \
  configs/train_tiny.yaml configs/train_medium.yaml /path/to/contract.yaml
```

Absolute paths are unavoidable: HyperParallel resolves `data_path` and
`pretrained_model_name_or_path` relative to its own repo root, not to this file.
